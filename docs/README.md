# SINGAN2 项目文档中心

> 本目录是 `Singan2_Lai_GBVE_SR_AI` 改造工程的**文档导航中心**。它既是 `Singan2_Lai_GBVE_SR_OLD` 源码的架构解读手册，也是本改造项目的规范、日志与执行路线总入口。

## 项目一句话定位

**SINGAN2.exe** 是一个 **Win32 对话框程序（C/C++，非 MFC）**，用于钞票（纸币）检测/验证算法研发——读取钞票扫描仪输出的**多波段图像数据**（MarinerFormat），通过梯度、二值化、浓度统计等图像处理提取 32 个特征值 `S2[1..32]`，并按国家分派到专用判定函数，最终输出/调试各国钞票的**真伪判定特征**。

## 关键速查

- **入口**：`WinMain` → `DialogBox(IDD_DIALOG)` + `DialogProc`（WinMain.cpp）
- **主处理**：`MainRun` → `MainRun1`/`MainRun2` → `ReadImgDataNew`（读图）→ `ALL32`（算特征）
- **特征计算核心类**：`C_SI2`（C_SI2.h/cpp）
- **国家分派**：`ALL32` 内 `switch (global_SelectCountry)` 分派到 `Euro_`/`China_`/`USA_` 等
- **配置文件**：`singan2.si2`（EXE 同目录，文本格式）
- **必须随 EXE 分发**：`GBV_DIV_H.bin`、`GBV版_DIV_H.bin`（readme 强调）
- **全局变量约定**：全部以 `global_` 前缀声明在 `MAIN.H`
- **源码编码**：日文注释（Shift-JIS），GBK 环境下请以日文/Shift-JIS 编码查看

## 重要注意事项（摘自 readme.txt 及代码）

1. 启动时若 `singan2.si2` 格式不兼容（V5 后新增 ATB/CTB/VTB），会抛异常无法进入应用，需替换最新配置。
2. 数据量上限约 2500 张（50MB Stack 限制，VS 工程已配 `Heap/Stack = 50MB`）。
3. 画图统计时 `funDatas1`/`funDatas2`（各 `MAX_DATA*4` 字符）合计约 43MB，注意内存。
4. 已知 BUG：不转载坐标就点 "Show Absolute" 会挂死；布局调整后资源编辑器可能无法打开（用文本编辑器改 `.rc`）。
5. 根目录 `MainRun.old.cpp` / `MainRun - perfect.cpp` 是历史备份，勿改。
6. **红线**：`Singan2_Lai_GBVE_SR_OLD` 目录禁止修改（见 07 文档第 7 节）。
