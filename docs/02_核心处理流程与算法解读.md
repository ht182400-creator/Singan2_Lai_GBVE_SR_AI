# 02_核心处理流程与算法解读

## 1. 启动流程（WinMain.cpp）

```text
WinMain
 ├─ InitCommonControlsEx（初始化公共控件）
 ├─ S_load()                       ← 读 singan2.si2，恢复上次配置
 ├─ DialogBox(IDD_DIALOG, DialogProc)
 └─ DialogProc 消息循环
     ├─ WM_INITDIALOG → InitMainDlg（初始化 Tab/滑块/下拉框/图像显示）
     ├─ WM_COMMAND → 按钮/菜单处理（IDC_RUN 运行、IDC_BACK/NEXT 翻页、IDC_SLIDER_* 滑块）
     ├─ WM_HSCROLL → 滑块：图像类型、颜色、梯度、二值化阈值
     ├─ WM_DRAWITEM → 图像绘制（绘制 global_oneimg 到对话框位图）
     └─ 关闭时 S_save() 保存配置
```

要点：

- **配置恢复**：启动即读 `singan2.si2`（S_load），退出时写回（S_save），保证"上次用的数据/币种/坐标"下次启动还在。
- **Tab 切换图像类型**：`IDC_TAB` 切换显示 1 字节/2 字节图像、红外、磁、厚度、UV、SRU 等不同波段。
- **拖放支持**：可把数据文件直接拖进对话框触发分析（`ReadImgDataNew` 入口之一）。

## 2. 主处理数据流（MainRun → ALL32）

```text
MainRun（循环处理所有记录）
 ├─ MainRun1 / MainRun2（双通道）
 │    ├─ CheckFile（CTemplateData 解析文件头）
 │    ├─ ReadImgDataNew（读第 global_Mai 条记录 → global_oneimg/global_twoimg）
 │    └─ 计算速度数据 global_small_image（5790/5791 速度表）
 ├─ ALL32（核心算法）
 │    ├─ InitAll32：读坐标文件、确定币种、清空 S2 与 global_etc
 │    ├─ 公共特征计算（C_SI2 各方法 → S2[1..16]）
 │    ├─ switch (global_SelectCountry) → Euro_/Chia_/USA_/Canada_/...（→ S2[17..32]）
 │    ├─ soil_soil（新旧污损判定）、smonly_func、outfunc（输出）
 │    └─ 保存本次结果
 ├─ 绘制：CreateGraph1/2 → OnDrawGraph（折线图）
 └─ 翻页显示下一枚
```

### 2.1 关键函数职责

| 函数 | 文件 | 职责 |
|---|---|---|
| `MainRun` | MainRun.cpp | 外层循环：枚数循环 + 双通道 + 调用 ALL32 + 绘图 |
| `MainRun1` / `MainRun2` | MainRun.cpp | 单通道准备：检查文件、读取图像、准备全局缓冲 |
| `ReadImgDataNew` | MainRun.cpp | 按 `global_Mai`（当前记录号）从模板数据中读取图像到 `global_oneimg` |
| `CheckFile` | CTemplateData.cpp | 解析文件头，算出各数据段偏移与 `dataCount` |
| `ALL32` | ALL32.CPP | 特征计算总入口：公共特征 + 国家分派 |
| `InitAll32` | ALL32.CPP | 读坐标文件（`global_Zparam`）、清空状态 |
| `CreateGraph1/2` | CreateGraph.cpp | 生成图形数据（`global_graph1_black/white`） |
| `OnDrawGraph` | OnDrawPaint.cpp | 把图形数据画到图形窗口（CGR_CLASS） |

## 3. 特征计算核心（C_SI2）

`C_SI2` 类（C_SI2.H / C_SI2.CPP）封装了单枚钞票的特征提取，方法前缀多为数字（如 `S2_1`…或语义名），核心计算项：

| 特征 | 说明 |
|---|---|
| 平均浓度 | `average_concentration` / `average_concentration2`（长手/短手两个方向的平均浓度） |
| 污损率 | `soil` / `soil_soil`：新旧污损（脏污）程度 |
| 相邻差分 | `Rinsetu2`：相邻像素差（边缘响应） |
| 梯度 | `Gradient`：Sobel/Roberts/Normal 梯度值 |
| 二值化 | `NITI`（NitiMain/NitiMain2）：阈值二值化后的加算值 |
| 红外白比 | `infrared_white_ratio2`：红外图像白色区域比例 |
| 磁/厚度 | 磁墨水、纸厚度相关统计 |
| 速度 | 结合 `global_small_image`（5790/5791）与除法表做速度校正 |

> **关键数据**：`S2[32]` 是贯穿全流程的特征值数组 —— `S2[1..16]` 为公共特征（所有国家都算），`S2[17..32]` 为国家特有特征。结果展示（`IDC_DSP_*` 控件）与 CSV 输出均依赖 S2。

## 5. 算法细节补充

### 5.1 图像处理算子

| 算子 | 说明 |
|---|---|
| `GRADIENT` | 梯度计算，含 Sobel / Roberts / Normal 三种模式，输出梯度图与特征 |
| `PREWITT` | Prewitt 边缘检测算子（3×3 卷积核） |
| `LAPLACIAN` | Laplacian 二阶微分算子，用于边缘锐化检测 |
| `NITI` | 二值化加算：按阈值对图像二值化后统计黑/白像素 |
| `smooth_median` | 中值滤波，去噪 |
| `To2byte` | 1 字节浓度图转 2 字节高精度图（`To2byte_orver_write` 为带覆盖写版本） |

### 5.2 速度校正

- 扫描仪以可变速度走纸，图像行间距随速度变化。
- `global_small_image[5790/5791]` 存储速度测量表，`bvmath.cpp` 的 `Rute`（整数开方）结合 `GBV_DIV_H.bin` 的除法表做行距/长度校正。

### 5.3 污损判定

- `soil` / `soil_soil`：对指定区域统计低浓度像素占比，判断钞票新旧（脏污）等级，作为防伪/ATM 回收判据之一。

## 6. 双通道（two）机制

- `global_twoimg` 等 `*2` 后缀变量为第二通道数据。
- 用于：两枚钞票对比、左右两路传感器、或两份文件对照分析。
- `MainRun2` 负责第二通道读取与 `ALL32` 第二次调用。

## 8. M1 POC 算法层探索成果（2026-08-20）

> 本节记录把 S2 算法从 C++ 移植到 Python 的过程与结论，对应 `poc/algo/` 下的实现。

### 8.1 移植边界（已确认）

- **算法读取的坐标来源是 `global_Zparam`（Z 参数 .txt），不是 ATB `.bin`**。
  - `ALL32.cpp` 的 `InitAll32` 用 `ReadZFile` 加载坐标到 `global_Zparam`；
  - `C_SI2.CPP` 各方法（`Sukasi1_LeftX[KIN]` 等）从 `global_Zparam` 取区域坐标；
  - ATB `.bin` 仅用于界面"Load ATB"显示区域列表，**不参与 S2 计算**。
  - 结论：POC 必须解析 `.txt`（`poc/parse/zahyo_reader.py`），与 `run_poc.py` 的 M0 用 `--atb` 不同。

### 8.2 中间波段计算（ReadImgDataNew 核心）

从 `global_onedat`（13 原始波段）计算 Img1..Img22，其中 Img7..Img15 为派生波段：

| 波段 | 公式（C++） | 说明 |
|---|---|---|
| Img7  | `Img1^2 * wTable[64] >> 16`（clamp 0..255） | 红外强调 |
| Img8  | `Img1 - Img3 + red_offset`（默认128，clamp 0..255） | 红外-赤外差分 |
| Img9  | `Img2 - Img3 + grn_offset`（默认128，clamp 0..255） | 绿-赤外差分 |
| Img10 | `abs(Img1 - Img2)`（clamp 0..255） | 红外-绿差绝对值 |
| Img11 | `Img1 - Img2`（clamp 0..255） | 红外-绿差 |
| Img12 | `(Img1-Img2)^2 * wTable[8] >> 16`（clamp 0..255） | 色差强调 |
| Img13 | `Img2 - Img1`（clamp 0..255） | 绿-红外差 |
| Img14 | `Img1 & Img2` | 与 |
| Img15 | `Img1 \| Img2` | 或 |

> POC 实现：`poc/algo/imageops.py::ImageEngine.compute_intermediate_waves()`

### 8.3 图像处理算子（Python 复刻）

| 算子 | 对应 C++ | POC 方法 | 要点 |
|---|---|---|---|
| 梯度 | `GRADIENT.CPP::Gradient` | `ImageEngine.gradient(gtype, amp)` | Sobel(0)/Roberts(1)/Normal(2)；内部 `Rute`(二分开方)/`Old_Rute`(线性开方)；Sobel/Roberts clamp [0,255]，Normal USHORT 截断 |
| 二值化 | `NITI.cpp::NITI` | `ImageEngine.niti(s)` | `val>=s ? 0xff : 0` |
| 平滑 | `smooth_median.cpp::smooth` | `ImageEngine.smooth()` | 3×3 均值 `sum* wTable[9]>>16` |
| 开方 | `bvmath.cpp::Rute/Old_Rute` | `ImageEngine._rute/_old_rute` | Rute 7 次二分迭代 |
| 除法表 | `WinMain.cpp::w_Read` | `poc/algo/wtable.py::load_w_table` | 读 `GBV_DIV_H.bin`(32768B)→16384 项 uint16 |

### 8.7 已知坑（2026-08-21 补充）

- `mariner_reader.build_onebyte_images` 只产出 13 个原始波段名（Img1..6, Img16..19, Img20..22），**缺少 Img7..15**，必须由 `compute_intermediate_waves` 计算。
- **`BLOCK_HEADER` 必须是 24 不是 32**：块头 = `sizeof(BYTE[24])`。用 32 会让波段数据整体偏移 8 字节，S2 计算全部错位（small_image 偏移验证 = `lengthMmFileHeader + 24` 佐证）。**已修复**。
- **区域边界不能用 numpy 负索引**：`arr[y+1:yy-1]` 当 yy=0 时取到整幅图（负索引），而 C++ `i < yy-1` 永不成立 → c=0。所有区域函数必须用 `_bounds(y_lo,y_hi,x_lo,x_hi)` 显式判断空区域。**已修复**。
- **差分对数**：`sub[:,0:-1]-sub[:,1:]` 只产生 w-1 对，C++ 是 w 对（j 从 j0 到 j1，比较 j 与 j+1，j+1 允许越界到 j1+1）。Rinsetu2/RINSETU 已改为 `arr[...,j0:j1+1]-arr[...,j0+1:j1+2]`。**已修复**。
- **原版 fallback 固定指针 bug**：`RINSETU`（C_SI2.CPP:1111-1141）和 `Siki_Kyotyo`（C_SI2.CPP:1235-1244）的 fallback 内层循环**没有 `img++`**，结果 = 380×`|buf[0]-buf[1]|` / 256×`buf[0]`。Python 必须复刻此 bug 才能对拍一致。**已复刻**。
- **`soil_soil` fallback 用 Img1**（C_SI2.CPP:1286），不是 Img3。**已修复**。
- **`Gradient`/`smooth` 只处理内部区域**（`i∈[1,Y-2], j∈[1,X-2]`），边界像素保持 twoimg 原始值（Inimg 拷贝）；`smooth` 额外 `buf += 中心像素` 并 clamp 255。**已修复**。
- `Rute` 用 `w_Table[2]`（约 32768），`Old_Rute` 是无限递增的线性开方，性能差但结果精确。
- `C_SI2` 的 `z_wariai`（速度换算）依赖 `small_image[5790/5791]`，未填充时退化为恒等变换。
