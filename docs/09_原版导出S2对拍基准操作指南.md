### 步骤 0：修复 si2 的 `[座標ファイル]` 路径

如果 `debug/singan2.si2` 里的 `[座標ファイル]` 指向不存在的路径（如 `Y:\Work\...`），必须改成**实际存在的 txt 文件路径**。否则 ELIA 弹窗会反复弹。

**推荐**：把 `[座標ファイル]` 改成 `E:\AI_Studio\NCR_tool\Singan2_Lai_GBVE_SR_OLD\ZAR\X_ATB_ZAR_132006050001.txt`（与 ATB .bin 配对的 Z 参数文本，**文件头需为 Shift-JIS `亂偡偐偟侾`**，可正常被 `ReadZFile` 解析）。

```powershell

$enc = [System.Text.Encoding]::GetEncoding(932)
$b = [System.IO.File]::ReadAllBytes($si2)
$s = $enc.GetString($b)
$s2 = $s.Replace("Y:\Work\GBVM\04_Area\X_ATB_DOP_5F1906040002.bin.txt",
                  "E:\AI_Studio\NCR_tool\Singan2_Lai_GBVE_SR_OLD\ZAR\X_ATB_ZAR_132006050001.txt")
[System.IO.File]::WriteAllBytes($si2, $enc.GetBytes($s2))
```

参考脚本：`poc/tools/fix_si2.ps1`（已完成 8-20 验证）。

## 4. CSV 格式与 S2 提取

CSV 由 `WinMain.cpp:1230-1236` 写出：

```
第 1 列      = 枚号 i            (1 .. 40, global_Mai=总枚数)
第 2~33 列   = S2[1..32]         (dindex=1..32)
第 34~43 列  = global_etc[1..10] (其它函数结果, j+33 偏移)
```

> **对拍提取规则**：取 CSV 每行的 **第 2~33 列**，即 `S2[1..32]`。
> 第 1 列是枚号（与 POC 的 `record_index` 对应），第 34 列起是 `global_etc` 非 S2 特征，忽略。
>
> **CSV 编码**：程序以 ANSI（系统代码页，中文系统是 GBK）写出，含日文 "枃栚"。POC 解析时需指定正确编码：
>
> ```python
> import pandas as pd
> df = pd.read_csv("a.csv", encoding="gbk", header=None,
>                  names=["枚号"] + [f"S2[{i}]" for i in range(1, 33)] + [f"ETC[{i}]" for i in range(1, 11)])
> s2 = df.iloc[:, 1:33].values  # shape (40, 32)
> ```

## 10. 后期改造要点（Web 化）

根据实测经验，以下原版交互问题在 Web 化时需要改进：

1. **"Change"按钮无效**：原版界面底部"Coordinate"栏的两个"Change"按钮在修改 Z 坐标路径时不可用。Web 化必须用直接读写文件的方式，并提供路径预览。
2. **窗口位置超出屏幕**：原版按 1400×1050 设计但实际渲染约 2068×1172，125% DPI 缩放下经常超出屏幕。Web 版天然自适应窗口。
3. **按钮隐藏/动态创建**：原版 "View All Result" 按钮在图像视图下隐藏、需要切到列表视图才动态创建。Web 版应始终显示所有操作按钮，避免 UI 状态机复杂。
4. **Create1 状态同步**：原版必须在 Setting 对话框点 OK 才能同步 Create1 状态（X 关闭无效）。Web 版应避免这种隐式状态同步。
5. **路径分隔符硬编码**：原版 si2 用 `Y:\Work\...` 这种本地盘符路径，无法跨平台。Web 版应使用相对路径或路径选择器。
6. **日文 → English（用户 2026-08-20 决策）**：后期优化把界面/日志/注释/CSV 表头/坐标段标题的全部日文改英文。涉及 Shift-JIS 编码文件必须用 `GetEncoding(932)` 转码，且**在算法对拍收敛后再做**（详见 06 文档 §11）。
