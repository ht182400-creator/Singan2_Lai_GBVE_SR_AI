# 01_项目架构总览

## 1. 项目定位

| 项 | 值 |
|---|---|
| 产品名 | SINGAN2.exe |
| 类型 | 钞票检测/验证（Banknote Validation）算法研发工具 |
| 形态 | Win32 桌面对话框程序（**非 MFC**，`DialogBox` + `DialogProc` 手写消息循环） |
| 平台 | Windows x86（Win32），VS2017（v141 工具集） |
| 语言 | C/C++（源码注释为日文，Shift-JIS 编码） |
| 数据源 | 钞票扫描仪多波段图像数据（MarinerFormat `.dat` 系列） |
| 产出 | 32 维特征值 `S2[1..32]`、判定结果、图形曲线（.GPH）、CSV 输出 |

**一句话架构**：*读配置 → 读多波段图像 → 公共特征计算（C_SI2）→ 按国家分派的专用特征计算 → 结果显示与图形化调试。*

## 2. 技术栈与工程配置

- **工程文件**：`SINGAN2.vcxproj`（MSBuild，v141）
- **配置**：Debug / Release 两种，输出 `.\Debug\SINGAN2.exe`
- **链接库**：`odbc32.lib`、`odbccp32.lib`（ODBC 数据库访问，用于结果记录）、`COMCTL32.lib`（公共控件）
- **编译选项**：
  - 多字节字符集（非 Unicode）
  - `RuntimeLibrary = MultiThreadedDebugDLL`
  - 栈/堆：`HeapReserveSize = 52428800`（50MB），`StackReserveSize = 52428800`
  - `GenerateDebugInformation = true`
- **资源文件**：`SINGAN2.rc`（对话框、菜单、图标）

## 3. 分层架构

```text
┌─────────────────────────────────────────────────────────────┐
│  UI 层（WinMain.cpp + SINGAN2.rc）                          │
│  DialogProc 消息循环 / 菜单 / Tab / 滑块 / 列表 / 图形窗口    │
├─────────────────────────────────────────────────────────────┤
│  流程编排层（MainRun.cpp / ALL32.CPP）                       │
│  MainRun → MainRun1/2 → ReadImgDataNew → ALL32 → 分派国家算法 │
├─────────────────────────────────────────────────────────────┤
│  算法层                                                      │
│  C_SI2（特征计算核心）                                       │
│  国家算法：Euro/Chia(中国)/USA/Canada/England/HongKong/...   │
│  图像处理：GRADIENT/PREWITT/LAPLACIAN/NITI/smooth_median     │
│  数学库：bvmath（Rute 整数开方）                             │
├─────────────────────────────────────────────────────────────┤
│  数据访问层                                                   │
│  CDataHeader / CTemplate / CTemplateData / CTemplateVTB      │
│  CFileAccess（文件 I/O 封装）                                │
│  C_SI2::LoadDat / save_load.cpp（结果/配置保存）             │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 关键设计约定

1. **全局函数 + 全局变量**（C 风格）：所有跨模块状态以 `global_` 前缀存放在 `MAIN.H`，由多个 .cpp 共享，无类封装（少数例外：`C_SI2`、`CTemplate*`、`CGR_CLASS`）。
2. **数据流单向**：文件 → `CTemplateData` 解析 → `global_oneimg/global_twoimg` 图像缓冲 → `C_SI2` 特征计算 → `S2[]` → 显示/绘图/保存。
3. **双通道支持**：`global_*2` 后缀变量为第二组数据（两枚钞票/两个文件对比分析）。
4. **国家算法插件式扩展**：`ALL32` 中 `switch (global_SelectCountry)` 一个 case 一个函数，新增国家 = 加 case + 新建函数。

## 5. 构建与发布

### 5.1 编译（Visual Studio 2017 或 MSBuild）

```bat
:: 命令行方式
msbuild SINGAN2.vcxproj /p:Configuration=Debug /p:Platform=Win32

:: 或直接打开 SINGAN2.sln 用 IDE 生成
```

**前置条件**：`GBV_DIV_H.bin` 与 `GBV版_DIV_H.bin` 必须放到 EXE 同目录（程序启动时 `LoadDat` 会读取，缺失则报错）。

### 5.2 发布（`_Publish.bat`）

```bat
@echo off
taskkill /f /im SINGAN2.exe
:: 等待进程退出
ping 127.0.0.1 -n 2 > nul
xcopy /e /y .\debug\SINGAN2.exe R:\Template.GBXX\Tools\GBVM\Singan2\
```

> 发布目标：`R:\Template.GBXX\Tools\GBVM\Singan2\`（模板工具链中的 GBVM 工具目录）。发布前需确保目标程序未运行，否则 `xcopy` 会因文件被占用而失败。

### 5.3 运行依赖

| 文件 | 用途 |
|---|---|
| `singan2.si2` | 配置文件（数据文件路径、币种、坐标文件、显示参数等） |
| `GBV_DIV_H.bin` | 除法表（`w_Table[8192]`，Rute 整数开方/速度校正用） |
| `GBV版_DIV_H.bin` | GBV 版除法表（用于 IR^/64 图） |
| 坐标文件（.bin.txt） | 各币种/面额的区域坐标参数，`singan2.si2` 中指定 |
| 数据文件（.dat / MarinerFormat） | 待分析图像数据 |

## 6. 已知限制与坑

1. **数据量上限**：约 2500 张/次（堆栈 50MB 限制）。
2. **内存大户**：图形统计 `funDatas1/2` 各 `MAX_DATA*4` 字节，两通道合计约 43MB。
3. **已知 BUG**：
   - 不转载坐标就点 "Show Absolute" → 程序挂死。
   - 资源布局调整后 VS 资源编辑器可能打不开 `.rc`（需文本编辑器）。
4. **编码坑**：源码日文注释为 Shift-JIS，中文 GBK 系统下 VS 默认以系统代码页打开会出现乱码，请用"日文(Shift-JIS) 代码页 932"查看。
5. **配置文件兼容**：V5 之后 `singan2.si2` 新增 ATB/CTB/VTB 相关字段，旧配置文件直接启动会异常。

## 7. 版本与历史（推测）

- 工程路径带 `GBVE_SR`：**Global Banknote Verification Engine - Security Review**（全球钞票验证引擎 - 安全评审版）。
- `_OLD` 后缀表示本仓库为旧版本存档；存在平行的 `Singan2_Lai_GBVE_SR_AI` 目录，说明后续可能有 AI 化改造分支。
- 根目录大量国家文件 + `ALL32` 集中分派 → 该工具服务于**多国钞票鉴别模板开发**。
