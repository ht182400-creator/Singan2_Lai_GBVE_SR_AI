# 10 界面与交互文档（原版基线 + Web 化对照复刻规格）

> 本文档由 **UI 设计师角色**维护，是 Web 化改造（M3a）的界面设计基线。
> 第 2 节描述**原版 Win32 界面**（业务语义来源，已附截图）；第 3 节描述 **Web 化对照复刻规格**（1:1 复刻原版，仅日文标签英文化）。
> 原版界面截图已提供（P1–P7，见第 5 节）；P8/P9 为对照原版由 AI 生成的 Web 复刻线框（见第 5.2 节）。

---

## 1. 文档目的与范围

| 项 | 说明 |
|---|---|
| 目的 | 1) 固化原版界面业务语义，避免 Web 化时丢失功能；2) 给出**原版 UI 1:1 对照复刻规格**（布局/菜单/按钮/交互照搬）；3) 统一日文→英文文案 |
| 适用范围 | M3a（WASM + HTTP API + React + ECharts）界面实现 |
| 关联文档 | 01 架构总览（分层）、05 Web 化可行性、06 §11 日文→英文决策、08 测试规范（UI 用例） |
| 角色 | UI 设计师（维护）、前端（实现）、测试专家（验收） |

**界面设计原则**：
1. **对照复刻，不重新设计**：Web 端全盘照搬原版布局、菜单、按钮与交互（见第 3 节），不引入新信息架构。
2. **仅日文标签英文化**：所有日文（すかし/赤外/汚れ…）在 Web 端一律英文，映射见第 4 节；菜单名/缩写（tool/View/Create1/Cont.）沿用原版。
3. **代码内日文全量替换**：**代码里所有日文引用或使用日文的地方，一律换成英文或中文**（含注释、字符串常量、日志、文件头段标题如 `【すかし１】`、UI 文案等），不允许残留任何日文。替换须在对拍基准稳定后执行，避免影响 `ReadZFile` 等文件头判断（见第 4 节与 06 §11.3）。
4. **先收敛算法，再动 UI**：界面文案/交互改造排在算法对拍稳定之后（见 06 §11）。

## 3. Web 化目标界面 = 原版 UI 对照复刻（M3a）

> **设计原则变更**：本项目的 Web 化目标是**对照原版 Win32 界面 1:1 复刻**，而非重新设计 UX。
