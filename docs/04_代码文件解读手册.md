# 04_代码文件解读手册

> 说明：本手册按根目录文件逐一解读。行数为估计值。全局变量均声明于 `MAIN.H`（`global_` 前缀）。

## 1. 入口与 UI 层

### WinMain.cpp（~3800 行）
- `WinMain`：初始化公共控件 → `S_load()` 读配置 → `DialogBox(IDD_DIALOG, DialogProc)`。
- `DialogProc`：处理 `WM_INITDIALOG`（`InitMainDlg` 初始化 Tab/滑块/列表/图形窗口）、`WM_COMMAND`（按钮/菜单）、`WM_HSCROLL`（滑块）、`WM_DRAWITEM`（绘制图像）、`WM_DROPFILES`（拖放文件）。
- `S_load` / `S_save`：读写 `singan2.si2`。

### SINGAN2.h / resource.h / SINGAN2.rc
- `resource.h`：控件 ID（`IDC_*`）、对话框 `IDD_DIALOG`、菜单资源。
- `SINGAN2.rc`：对话框布局、位图、图标、菜单资源（Shift-JIS 编码）。

## 2. 全局声明层

### MAIN.H（核心头文件）
- 国家代码常量：`CCODE_EURO / CCODE_CHINA / CCODE_USA / CCODE_CANADA / CCODE_HONGKONG / CCODE_ENGLAND / CCODE_SINGAPOLE / CCODE_SWISS / CCODE_TURKEY / CCODE_POLAND / CCODE_CZECH / CCODE_SAUDI / CCODE_SOUTH_AFRICA / CCODE_INDONESIA / CCODE_TAIWAN / CCODE_THAI / CCODE_MALAYSIA` 等。
- 图像缓冲全局变量：`global_oneimg/global_oneimg2/global_twoimg`、`global_oneimg_IR/MAG/THICK/UV/SRU`、`global_small_image`（5790/5791 速度表）。
- 状态全局变量：`global_SelectCountry`、`global_Mai`（当前记录号）、`global_Zparam`（坐标参数）、`global_etc`、`S2[32]`。
- 所有跨文件函数声明。

## 3. 流程编排层

### MainRun.cpp（~3100 行）
- `MainRun`：主循环（枚数 × 双通道）。
- `MainRun1` / `MainRun2`：单通道准备（读图、算速度）。
- `ReadImgDataNew`：按 `global_Mai` 读取图像到缓冲。
- 统计函数：`funDatas1/2` 图形统计。

### MainRun1.cpp / MainRun2.cpp
- 主循环的细化分工（单双通道读取/处理细节），配合 MainRun.cpp 使用。

### ALL32.CPP（核心分派）
- `ALL32`：特征计算总入口 → `InitAll32` → 公共特征（C_SI2）→ `switch(global_SelectCountry)` 分派国家函数 → 输出。
- `InitAll32`：读坐标、清状态。
- 各国函数：`Euro_`、`Chia_`、`USA_`、`Canada_`、`HongKong_`、`England_` 等。

### save_load.cpp
- 结果保存/加载、CSV/数据库输出。

## 4. 数据访问层

### CDataHeader.h/cpp
- 数据文件头结构定义与解析。

### CFileAccess.h/cpp
- 文件 I/O 封装（打开/读/写/定位，带偏移的文件访问）。

### CTemplate.h/cpp
- 模板基类：记录结构、读写框架。

### CTemplateData.h/cpp
- 数据文件解析：`CheckFile` 计算数据段偏移与 `dataCount`；提供记录级读取。

### CTemplateVTB.h/cpp
- VTB 模板解析（特征值模板库）。

### CTest.h/cpp
- 模板/测试校验。

### C_SI2.H / C_SI2.CPP（核心类）
- 特征计算类 `C_SI2`：`average_concentration`、`soil`、`Rinsetu2`、`Gradient`、`NITI`、`infrared_white_ratio2` 等 32 维特征提取。
- `LoadDat`：加载数据文件。

## 5. 算法层

### bvmath.cpp
- 数学库：`Rute`（整数开方，用 `w_Table[8192]` 除法表）、`Pow` 等整数运算优化。

### 图像处理
| 文件 | 算法 |
|---|---|
| `GRADIENT.cpp` | 梯度计算（Sobel/Roberts/Normal 等） |
| `PREWITT.CPP` | Prewitt 边缘算子 |
| `LAPLACIAN.cpp` | Laplacian 二阶微分 |
| `NITI.CPP` | 阈值二值化加算 |
| `smooth_median.cpp` | 中值平滑 |
| `To2byte.cpp` / `To2byte_orver_write.cpp` | 1字节图转2字节图（后者带覆盖写） |
| `MainGradient.cpp` | 主梯度流程 |
| `CreateGraph.cpp` | 图形数据生成 |
| `OnDrawPaint.cpp` | 图形绘制 |

### CGR_CLASS.cpp（CGR_CLASS 类）
- 图形绘制类：折线图、坐标轴、网格、标注渲染。

## 9. 常见修改场景定位

| 想改什么 | 去哪里改 |
|---|---|
| 加一个新国家 | `ALL32.CPP` 加 case + 新建国家函数文件 |
| 改公共特征 | `C_SI2.CPP` |
| 改某国特征 | 该国 .cpp 文件 |
| 改界面 | `WinMain.cpp` + `SINGAN2.rc` |
| 改数据解析 | `CTemplateData.cpp` / `CDataHeader.cpp` |
| 改保存输出 | `save_load.cpp` |
| 改绘图 | `CreateGraph.cpp` / `OnDrawPaint.cpp` / `CGR_CLASS.cpp` |
